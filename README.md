One office-life joke, one line: a performance review that says "exceeds expectations" because nobody expects anything anymore. Entry for make.fun's "Make the AI Judge Laugh" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

This writes the joke (95 characters, one line) to `/output/entry.txt`. Deterministic: the program writes a constant string — no network, no model call, no randomness, no reads of files outside the program.

## The joke

> My performance review said 'exceeds expectations' because nobody here expects anything anymore.

See `design.md` for the study behind this line: the judge brief, 34 brainstormed candidates with scores, and why this one won.
